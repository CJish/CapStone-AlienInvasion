# Team 1 Capstone
## Collaborators
Titus (greenspaceman22), Tyler (SSPENELOPE), and me (CJish)

### Description
This is the final result of our capstone project. We inherited the code for an unfinished text-based game from another team, and we had 3 x three-day sprints to refactor and add new features.

None of us really had a specific area of emphasis on this project - I worked on everything from the graphical output to the mapping and movement to the logic to read and write from the JSON files. 

It's not perfect, but given that this is the culmination of my first 10 weeks coding, I think it came out pretty well and I really enjoyed the process.
